# F026 — Autocomplete de @menções

## Status
Implementado

## Objetivo
Ao digitar `@` em comentários e na nova publicação, mostrar lista de
membros ativos para escolher o display name.

## Critérios
- [x] Dropdown ao digitar `@` (com ou sem filtro parcial)
- [x] Inserção do `@DisplayName` exato (compatível com resolução atual)
- [x] Teclado: ↑↓, Enter/Tab, Escape
- [x] Usado em comentários/respostas e composer
